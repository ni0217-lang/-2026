# Busan 6 Days Travel App

2026/10/1–10/6 釜山六日旅行行程 Web App。

## GitHub Pages
1. 建立 GitHub repository，例如 `busan-trip-2026`。
2. 將 `index.html` 與本 README 上傳到 repository 根目錄。
3. GitHub → Settings → Pages → Deploy from a branch → `main` / root。
4. 等待 GitHub Pages 部署完成，即可把網址分享給朋友。

## 功能
- 6 天分頁行程
- 每個時段都有交通／票券／餐食／購物標籤
- Google Maps 與 Naver Map 導航按鈕
- Visit Busan Pass 使用提醒
- 官方票價／營業時間的目前資料註記
- 手機版優先設計，可直接加入 iPhone 主畫面

## 注意
交通時間是行程規劃估算，不是即時導航；計程車費以跳表為準。景點、活動、Pass 優惠及餐廳營業狀況可能變動，出發前請再次確認。
